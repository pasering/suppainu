index.html をブラウザで開いて遊びます。オンライン対戦では HTTPS 上（GitHub Pages 等）への配置を推奨します。

【基本仕様】
- 最大4人。人間とCPUを混在可能
- PeerJS / WebRTCによるオンライン同期
- ゲーム時間：さっくり / 普通 / ロング
- 幼少期から円熟期まで7時代
- 進路、就職、昇進、恋愛、結婚、子ども、物件、カード、資産形成
- プラス／マイナス／成長／交流はそれぞれ専用イベントを使用
- 幼少期・小学生・中学生・高校生・円熟期は各系統20種（通常10＋3択10）
- 大人前半・大人後半は各系統40種（通常20＋3択20）
- 出来事マスは4系統からランダムに発生
- 各時代に大ラッキーマス2個・大不幸マス2個
- イベントは時代別に多数収録し、直近イベントの連続重複も抑制
- 収入マスは通過時に給料・家族収入・物件収入を受給し、昇進チャンスも発生
- BGM / 効果音は個別ON/OFF、全体音量調整対応
- BGMは通常・明るい出来事・大勝負・リザルトなど状況に応じて切り替わります
- 同じブラウザでは対戦状態を自動保存し、更新やブラウザ終了後の復帰に対応

【公開方法】
assets フォルダを含め、フォルダ構成を保ったままGitHub Pages等へ配置してください。
ZIPファイルそのものではなく、解凍した中身をアップロードします。

【操作】
- 自分の手番でルーレットを回します。
- 出目確定後、クリック / タップでコマを進めます。
- 停止中は盤面のマスをクリック / タップすると、そのマスの説明を確認できます。
- 所持カードは効果と「手番継続 / 手番終了」を確認して使用できます。カードマス・チャンス・一部イベントから入手できます。
- 盤面右上の「MAP全体」で全景表示を切り替えられます。次の行動時には通常表示へ戻ります。
- ゲーム中のトップボタンで一時的にトップ画面へ戻れます。

【盤面表示】
- プラスは青、マイナスは赤など、マス外周色を強調
- 成長は本、仕事はカバンなど、用途ごとにアイコンを整理
- 現在手番のコマから進行方向を点滅矢印で表示
- 各時代に分かれ道があり、分岐地点自体は通常の出来事マスとしてイベントも発生
